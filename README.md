Executive Summary
This report presents the implementation and evaluation of two state-of-the-art CNN architectures (ResNet50 and EfficientNetB0) for multi-task facial expression recognition. The models simultaneously predict categorical emotions (8 classes) and continuous affective dimensions (valence and arousal). While the technical implementation is complete and follows industry best practices, the models achieved limited accuracy (12.2% and 11.2%), revealing fundamental challenges with dataset imbalance that require specialized solutions beyond standard training approaches.
